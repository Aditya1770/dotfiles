# Keybinds
## Applications and windows

| Keybind                  | Action                         |
| ------------------------ | ------------------------------ |
| `Super + Enter`          | Open Kitty                     |
| `Super + Shift + Enter`  | Open floating Kitty            |
| `Super + B`              | Open Brave                     |
| `Super + E`              | Open Nemo                      |
| `Super + Shift + E`      | Open floating Nemo             |
| `Super + D`              | Open Fianchetto launcher       |
| `Super + Q`              | Close active window            |
| `Super + Space`          | Toggle floating                |
| `Super + F`              | Toggle fullscreen              |
| `Super + C`              | Center active window           |
| `Super + P`              | Toggle pseudotiling            |
| `Super + J`              | Toggle Dwindle split direction |
| `Super + Shift + Escape` | Exit Hyprland                  |

## Window focus and movement

| Keybind             | Action            |
| ------------------- | ----------------- |
| `Super + ←`         | Focus left        |
| `Super + →`         | Focus right       |
| `Super + ↑`         | Focus up          |
| `Super + ↓`         | Focus down        |
| `Super + Shift + ←` | Move window left  |
| `Super + Shift + →` | Move window right |
| `Super + Shift + ↑` | Move window up    |
| `Super + Shift + ↓` | Move window down  |

## Workspaces

| Keybind                    | Action                       |
| -------------------------- | ---------------------------- |
| `Super + 1–9`              | Switch to workspace 1–9      |
| `Super + 0`                | Switch to workspace 10       |
| `Super + Shift + 1–9`      | Move window to workspace 1–9 |
| `Super + Shift + 0`        | Move window to workspace 10  |
| `Super + Mouse wheel down` | Next workspace               |
| `Super + Mouse wheel up`   | Previous workspace           |

## Mouse

| Keybind              | Action        |
| -------------------- | ------------- |
| `Super + Left drag`  | Move window   |
| `Super + Right drag` | Resize window |

## Volume and media

| Keybind       | Action                       |
| ------------- | ---------------------------- |
| `Volume Up`   | Increase volume and show OSD |
| `Volume Down` | Decrease volume and show OSD |
| `Volume Mute` | Toggle mute and show OSD     |
| `Play`        | Play/pause media             |
| `Pause`       | Play/pause media             |
| `Next`        | Next track                   |
| `Previous`    | Previous track               |

## Brightness

| Keybind           | Action                           |
| ----------------- | -------------------------------- |
| `Brightness Up`   | Increase brightness and show OSD |
| `Brightness Down` | Decrease brightness and show OSD |

## Screenshots and colours

| Keybind                | Action                             |
| ---------------------- | ---------------------------------- |
| `Print Screen`         | Select an area and copy screenshot |
| `Super + Print Screen` | Copy full-screen screenshot        |
| `Super + Shift + C`    | Pick a colour and copy its value   |

## Fianchetto and utilities

| Keybind             | Action                            |
| ------------------- | --------------------------------- |
| `Super + D`         | Application launcher              |
| `Super + V`         | Clipboard manager                 |
| `Super + .`         | Emoji picker                      |
| `Super + L`         | Old external power-menu script    |
| `Super + Shift + N` | Toggle SwayNC notification centre |
| `Super + Shift + R` | Run Waybar script                 |
| `Super + Shift + M` | Run mouse script                  |

## Resize mode

Press `Super + R` to enter resize mode.

| Key while in resize mode | Action            |
| ------------------------ | ----------------- |
| `←`                      | Resize left       |
| `→`                      | Resize right      |
| `↑`                      | Resize upward     |
| `↓`                      | Resize downward   |
| Two arrow keys together  | Diagonal resizing |
| `Escape`                 | Exit resize mode  |
